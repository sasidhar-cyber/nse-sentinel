# Authorized Lab Demonstration Workflow

1. Record written authorization, target, permitted ports, test window, and exclusions.
2. Set up a private/host-only lab VM or local training service.
3. Confirm the target address and run a basic service inventory.
4. Review the selected NSE script and execute only against the approved lab host.
5. Save sanitized raw output in a local evidence folder.
6. Validate observations manually and separate facts from assumptions.
7. Prepare the report with evidence, impact, severity rationale, remediation, and retest status.

192.0.2.10 is reserved for documentation and is not a real lab target. Substitute only an authorized target.
